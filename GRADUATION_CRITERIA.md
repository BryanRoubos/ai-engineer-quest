# Junior AI Engineer Graduation Criteria

This document ships with AI Architect Quest. It is a self-assessment, not a certification or hiring guarantee.

| Outcome | Level | What to build | Evidence |
|---|---|---|---|
| Backend independence | 1 | API with SQL, authentication, tests, CI | Quickstart, requests, failing tests and green CI |
| AI integration | 3 | Real model integration, RAG, evaluation, fallbacks | Golden examples, citations and negative tests |
| Deployment | 4 | Docker and Kubernetes deployment, probes, RBAC | Manifests, pod status, restart evidence |
| Troubleshooting | 6 | Diagnose and fix three different simulated incidents | Logs, commands, root cause and fixes |
| Portfolio | 8 | Two reproducible projects | Repo links, demo, tests, diagram, benchmarks |
| Team experience | 8 | Collaborate on reviewed engineering work | PRs, comments, decisions, clearly attributed contributions |

## How to use
1. Open the linked level and build the project.
2. Run the instructions on your own machine and keep actual outputs.
3. Commit evidence in GitHub and explain what worked, what failed and why.
4. Tick graduation criteria in the lesson Check tab only when you can demonstrate them.
5. Revisit the integrated Career Readiness page to see gaps for your target job.

Completing a checklist is self-reported, not independently graded.
